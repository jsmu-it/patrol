02 / GPS & Geotagging

Pelacakan Lokasi Presisi Tinggi

Bagaimana GPS Tracking Bekerja?

1
Ambil Koordinat GPS

Latitude, longitude, dan altitude dari device

2
Validasi Akurasi

Minimal akurasi 50 meter untuk data valid

3
Simpan dengan Timestamp

Koordinat + waktu sebagai bukti absensi

4
Visualisasi di Map

Admin melihat lokasi di Google Maps

📍 Data yang Direkam

Latitude, Longitude, Accuracy, Altitude, Timestamp, Device ID, IP Address

🗺️ Google Maps Integration

📊 Export untuk Audit

Semua data lokasi dapat di-export PDF/Excel untuk keperluan audit

02 / Selfie Verification

Verifikasi Identitas Visual

Mengapa Selfie Wajib?

  • 🛡️
    Mencegah Titip Absen

    Foto wajah memastikan yang absen adalah orangnya langsung

  • 📸
    Bukti Visual

    Dokumentasi kehadiran yang tidak bisa dipalsukan

  • 👔
    Cek Kerapian Seragam

    Admin bisa memantau penampilan petugas

  • ⏱️
    Watermark Otomatis

    Waktu dan lokasi tercetak di foto

✅ Alur Verifikasi

Buka Kamera → Ambil Selfie → Upload ke Server → Tampil di Laporan

📂 Penyimpanan Aman

Foto dienkripsi dan disimpan di cloud dengan retensi sesuai kebijakan

🔒 Akses Terbatas

Hanya admin berwenang yang bisa mengakses foto absensi
